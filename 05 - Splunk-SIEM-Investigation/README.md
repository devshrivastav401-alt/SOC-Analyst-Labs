# Lab 05 — Splunk SIEM Investigation

## Objective
Perform a practical SIEM investigation in Splunk using Windows security events, identify suspicious authentication/process activity, and document the investigation like a SOC Analyst L1.

## Lab Status
🚧 In Progress

## Planned Tasks
1. Prepare Splunk and ingest Windows security logs
2. Verify the data source and fields
3. Search authentication events
4. Investigate failed and successful logons
5. Analyze process creation events
6. Build an event timeline
7. Write investigation SPL queries
8. Identify suspicious indicators and map relevant MITRE ATT&CK techniques
9. Document findings and evidence
10. Produce the final incident report

## Evidence
Screenshots will be stored in the `Screenshots/` directory.

## Queries
Investigation SPL queries will be stored in the `Queries/` directory.
