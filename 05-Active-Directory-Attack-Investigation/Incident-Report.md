# 🚨 Incident Report — Windows Authentication & AD-Style Investigation

## Executive Summary

A controlled SOC Analyst L1 investigation was conducted on a standalone Windows workstation to analyze authentication failures, local group enumeration, privileged logon activity, and PowerShell Script Block Logging.

The workstation was confirmed to be **WORKGROUP / not domain-joined**. As a result, this exercise does not represent a real Active Directory compromise. Instead, it demonstrates an AD-style investigation workflow using Windows endpoint telemetry.

**Final assessment:** 🟢 Benign / No confirmed compromise

## Key Findings

1. **Event ID 4799 — Local group enumeration:** PowerShell activity enumerated local group membership. In this controlled lab, the activity was benign and generated during investigation.
2. **Event ID 4625 — Failed authentication:** Three controlled invalid-password attempts against the local `Administrator` account were successfully detected. The events contained status `0xC000006D` and substatus `0xC000006A`.
3. **Event ID 4624 — Successful authentication check:** No successful Administrator logon was identified as a result of the controlled failures. The nearby successful events were SYSTEM service logons.
4. **Event ID 4672 — Special privileges:** The reviewed events belonged to the SYSTEM account and reflected normal privileged service activity, not evidence of privilege escalation.
5. **Event ID 4104 — PowerShell Script Block Logging:** Reviewed script blocks were Windows troubleshooting/input-method related scripts and investigation commands. No clear malicious PowerShell behavior was identified.

## MITRE ATT&CK Analysis

### T1087 — Account Discovery
Local account/group enumeration is relevant to account discovery. In this exercise, the activity was generated by the analyst and was not evidence of attacker behavior.

### T1059.001 — PowerShell
PowerShell was used for telemetry collection and analysis. Event ID 4104 provided visibility into Script Block Logging. The reviewed activity was assessed as benign.

## Assessment

### 🟢 Benign / No Confirmed Compromise

The telemetry demonstrates a realistic SOC L1 investigation workflow but does not establish an actual attack.

The three failed Administrator authentications were intentionally generated for detection testing. No corresponding successful Administrator logon was identified. The 4672 events were associated with SYSTEM, and the reviewed 4104 events did not reveal clear malicious PowerShell execution.

The evidence supports a **benign controlled lab scenario with no confirmed compromise**.

## Recommended Actions

1. Preserve the relevant Windows Security and PowerShell event evidence.
2. Continue monitoring repeated authentication failures in a production environment.
3. Correlate authentication failures with successful logons, source addresses, and account context before escalating.
4. Investigate unusual account/group enumeration when it occurs outside expected administrative activity.
5. In a future lab, perform the same workflow against an isolated real Active Directory domain and include domain-controller/Kerberos telemetry.
6. Forward the telemetry to a SIEM in a future lab for centralized correlation and alerting.
