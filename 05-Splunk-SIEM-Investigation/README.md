# 🛡️ Lab 05 — Splunk SIEM Investigation

## 🎯 Objective

Perform a SOC Analyst L1 investigation using Splunk to search, triage, correlate, and document Windows security events.

## 🔎 Investigation Focus

- SIEM alert triage
- Search Processing Language (SPL)
- Windows Security Event analysis
- Authentication investigation
- Failed and successful logon correlation
- IOC identification
- Timeline correlation
- Evidence-based incident assessment

## 🧪 Scenario

A controlled SIEM environment contains Windows security telemetry associated with suspicious authentication activity. The analyst uses Splunk and SPL to identify relevant events, correlate evidence, investigate the activity, and document findings.

> **Lab status:** In Progress

## 🛠️ Tools

- Splunk
- Search Processing Language (SPL)
- Windows Security Events
- Windows Event Viewer
- GitHub
- Markdown Documentation

## 📋 Investigation Workflow

1. Prepare the Splunk environment.
2. Confirm relevant Windows telemetry is available.
3. Identify suspicious authentication activity.
4. Search events using SPL.
5. Correlate Event IDs such as 4625 and 4624.
6. Analyze users, hosts, source IPs, timestamps, and related fields.
7. Build an investigation timeline.
8. Identify indicators and supporting evidence.
9. Assess the activity using available telemetry.
10. Document findings and recommended next steps.
11. Capture screenshots as evidence.

## 📸 Evidence

Screenshots will document the Splunk Search & Reporting interface, SPL queries/results, event details, correlated timeline, and final investigation evidence.
